# Screenshots

存放产品截图，被主 README.md 引用。

## 当前使用的截图

| 文件名 | 说明 | 内容 |
|--------|------|------|
| `landing.png` | 着陆页 | Hero 区域，含产品演示卡片 |
| `dashboard.png` | 工作台首页 | 数据概览、4 个快捷入口、最近查看 |
| `projects.png` | 项目列表 | 多 SKU 卡片网格，含平台徽章和进度条 |
| `templates.png` | 模板中心 | 平台模板 + 行业模板分类 |

## 命名规范

- 全部小写，单词用连字符分隔
- 格式：PNG（界面截图）/ GIF（流程演示，<5MB）
- 推荐尺寸：1600×900 或 16:9 比例
- 单张文件 < 500KB（用 [TinyPNG](https://tinypng.com) 压缩）

## 怎么截

- **Windows**：`Win + Shift + S` 调出截图工具
- **Mac**：`Cmd + Shift + 4` 选区截图
- **整页截图**：Chrome DevTools (`F12`) → `Cmd/Ctrl + Shift + P` → "Capture full size screenshot"

## 提示

- 截图前清空敏感内容（真实邮箱、API Key 等）
- 浅色模式截图视觉更稳定（也可同时提供深色模式）
- 上线前 Hard refresh 一遍，确保是最新 UI
