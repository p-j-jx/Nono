# Screenshots

Place product screenshots here. Referenced from the main README.md.

## Required Screenshots

| Filename | Description | Recommended size |
|----------|-------------|------------------|
| `landing.png` | 着陆页全景或 Hero 区域 | 1600x900 |
| `dashboard.png` | 工作台主界面 | 1600x900 |
| `generation.png` | 文案生成结果展示 | 1600x900 |
| `quality.png` | 质量检查报告 | 1600x900 |

## Tips

- Use PNG format for sharp UI screenshots
- Keep each file under 500KB (compress with [TinyPNG](https://tinypng.com))
- Capture in light mode for consistency (or provide both light/dark)
- Crop to 16:9 aspect ratio when possible
- For motion demos, use GIF/WebM under 5MB

## How to capture

**Windows**: Win + Shift + S → Snipping Tool
**Mac**: Cmd + Shift + 4 → Screenshot tool
**Chrome DevTools**: Cmd/Ctrl + Shift + P → "Capture full size screenshot"
